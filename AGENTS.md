## TaskPlanner workflow

Tasks are stored in `.tasks/`. Select the highest-priority task from `Next`,
then `Backlog`, unless the user selects a task. Move it to `In Progress`
before substantive implementation. Every implementation task needs a concise
`### Plan`; after verification, summarize the result, move it to `Done`, and
add a short entry to `.tasks/WORK_LOG.md`.
